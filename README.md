# live-cv

Roman Gusevski's personal CV/resume site — React + Vite + TypeScript + Tailwind CSS, EN/RU, light/dark theme.

## Run locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173` (or the next free port).

## Other commands

```bash
npm run build    # typecheck + production build, output in dist/
npm run preview  # serve the production build locally
npm run lint      # oxlint
```

There is no test suite configured yet.
